# 🌍 판게아 게임

고1 통합과학 "지질 시대와 화석" 단원 퀴즈로 진행하는 온라인 카드 게임입니다.
2~4명이 방 코드를 공유해 함께 접속하고, 공유 보드 위의 6개 대륙 조각을
퀴즈를 맞혀 중심으로 밀어 넣어 판게아를 완성합니다.

## 게임 규칙 요약

- 각 플레이어는 효과 카드 4장을 손에 들고 시작합니다.
- 자기 턴에 카드 1장(1칸 전진 / 2칸 전진 / 전체 조각 1칸 전진)을 내고,
  즉시 새 효과 카드를 뽑아 손을 4장으로 채웁니다.
- 카드를 낸 뒤 퀴즈 카드를 뽑아 문제를 풉니다. 정답이면 낸 카드의 효과가
  실제로 발동되고, 오답이어도 카드는 사용됩니다. 퀴즈 카드는 정답 여부와
  상관없이 덱 맨 아래로 돌아갑니다.
- 대륙 조각(유라시아, 아프리카, 남극-오스트레일리아, 북아메리카, 남아메리카,
  인도)은 크기에 따라 트랙 길이와 점수가 다릅니다. 조각을 완성(트랙 끝까지
  이동)시킨 마지막 플레이어가 그 조각의 점수를 가져갑니다.
- 조각은 제거되지 않고 보드에 남아 판게아 실루엣을 채워 나가며, 모든 조각이
  완성되면 게임이 종료되고 누적 점수가 가장 높은 사람이 승리합니다.

## 개발

```bash
npm install
npm run dev
```

## 배포 (Vercel)

레포를 Vercel에 연결하면 별도 설정 없이 바로 배포됩니다.

> ⚠️ 게임 상태는 서버 메모리(Node.js 프로세스)에 저장됩니다. 소규모 동시
> 접속(교실 단위)에서는 문제없이 동작하지만, 트래픽이 커져 서버리스
> 인스턴스가 여러 개로 스케일되면 방 상태가 어긋날 수 있습니다. 그런
> 경우 `lib/store.ts`의 인메모리 Map을 Vercel KV 등 외부 저장소로
> 교체하는 것을 권장합니다.
